EAT YOUR WEIGHT

Este documento contiene toda la información relacionada con el trabajo.
------------------------------------------------------------------------------------------------------------------------------------------
¿Qué estamos entregando?
Un proyecto XSLT, conteniendo dos xml, uno con datos recogidos a mano, y otro con datos recogidos y exportados por Access, contando de sus xsd.
Además de contar con el proyecto de HTML del primer trimestre.
------------------------------------------------------------------------------------------------------------------------------------------
¿Cómo se debe de mirar?
La página está hecha para que sea muy intuitiva de utilizar. Al principio del todo aparece una imágen
a la calculadora imc la cuál aconseja según la puntuación el tipo de plan que se ha de seguir (al clicar se abrirá en una ventana externa).

Una vez en la página principal. Tendrémos una barra lateral, con los tipos de platos que hay, y los tipos de alérgenos. Al pulsar sobre "Tipos" o "Alergias"
nos dirigirá a una parte de la página. Contamos con una flecha en la esquina inferior derecha que nos permitirá volver arriba del todo.

Al final de la página tenemos un apartado que indica los códigos postales en los que se permite hacer envio. (Datos recopilados en Access y exportados)
------------------------------------------------------------------------------------------------------------------------------------------
¿Qué necesito para verlo?
Para visualizar nuestra página web, deberemos de usar la extension live server de Visual Studio Code, y abrir el archivo eatYourWeight.xml
------------------------------------------------------------------------------------------------------------------------------------------
USO DE ELEMENTOS XSL:
Uso de for-each y de Sort en el sidebar para mostrar ordenados los alérgenos.
Uso de Value-Of en diferentes partes del xsl, entre ellas para mostrar los nombres de los platos y las calorías.
Uso de Choose y When para la sección de tipos.
Uso de Template para seleccionar los nodos.
