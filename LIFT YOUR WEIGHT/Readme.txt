LIFT YOUR WEIGHT

Este documento contiene toda la información relacionada con el trabajo.
------------------------------------------------------------------------------------------------------------------------------------------
¿Qué estamos entregando?
Una página web en la que se puede calcular el índice de masa corporal y la cuál proporciona diferentes planes de dieta.
------------------------------------------------------------------------------------------------------------------------------------------
¿Cómo se debe de mirar?
La página está hecha para que sea muy intuitiva de utilizar. Al principio del todo aparece la calculadora imc la cuál aconseja según la puntuación el tipo de plan que se ha de seguir. Una vez conseguida la puntuación, el usuario puede decidir si utilizar uno de nuestros planes o no.
------------------------------------------------------------------------------------------------------------------------------------------
¿Qué necesito para verlo?
Para visualizar nuestra página web no se requiere de ningún programa externo, simplemente con contar con un navegador web actualizado y con la carpeta descomprimida del trabajo se puede utilizar.
